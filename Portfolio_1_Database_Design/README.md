# Portfolio 1 – Database Design and Modelling

## Case Study
Miva Open University – Postgraduate Academic Management System.

## Objective
To design and implement a relational database for managing selected postgraduate academic activities, including faculties, departments, programmes, students, courses, enrolments and academic results.

## Implementation
The database was implemented using PostgreSQL through Supabase.

The design includes:
- Ten relational tables.
- Primary and foreign keys.
- Unique and CHECK constraints.
- Relationships between academic entities.
- Fictional sample records.
- SQL queries for relationship validation.

## Design Documentation
- Database schema
- Data dictionary
- Entity Relationship Diagram
- Normalisation documentation
- SQL implementation scripts
- Constraint and relationship validation evidence

## Data Limitations
The faculty and department structure is a proposed academic model. Student and lecturer records, course codes and course details are fictional or illustrative and are not represented as Miva's actual internal records.

## Conclusion
The implementation establishes a relational database foundation for the subsequent portfolio activities involving query optimisation, transaction processing, NoSQL and distributed database concepts.
